# 口袋偶像类 UI 参考

本目录保存项目早期讨论使用的外部界面截图，仅作为信息架构、交互层级和视觉气质参考。截图中的文字、名称、头像、品牌标识和具体业务数据不是项目需求，也不应直接复制到成品中。

## 文件说明

- `01-fan-list-ranking.png`：粉丝列表/应援段位界面。可参考头像、昵称、等级、身份标签和关系标签的高密度卡片布局。
- `02-idol-profile-tools.png`：偶像个人主页。可参考个人状态、粉丝统计、功能入口和底部导航的组织方式。
- `03-workbench.png`：偶像侧工作台。可参考“翻牌、通告、粉丝维护”等待办任务的分区和截止提示。

## 可借鉴方向

- 竖屏优先、单手操作。
- 用“偶像业务 App”包装核心游戏系统，让功能入口成为世界观的一部分。
- 以工作台汇总每日任务，以列表处理批量内容，以个人主页承载长期成长。
- 用头像、等级、标签和颜色帮助玩家快速识别粉丝类型与关系状态。
- 将待处理数量、截止时间和未读提醒转化为回合压力。

## 需要重新设计的部分

- 使用原创团体、角色、头像、图标、文案和品牌视觉。
- 不照搬原应用的页面比例、配色、图标或完整布局。
- 标签应服务于游戏决策，避免只展示装饰性数据。
- 信息密度需适配小屏设备，并为重要选择保留清晰的操作区域。
