## 使用边界

- 官方公布的活动规则、商品机制和资源激励可以作为讨论事实，但 NPC 的态度、吐槽和玩梗均为虚构创作。
- 涉及诉讼、合约、税务或个人名誉的内容，只能描述为“相关方公开声明的主张”。在裁判或权威结论公开前，不得把任何一方的指控写成已证实事实。
- 后续编辑时优先替换为更近期的一手公告；二手报道只用于补充检索，不覆盖一手来源。
- 不写成员私生活、住址、行程跟踪或来源不明的匿名爆料。
- 本地历史翻牌只用于提炼短句、语气词、吐槽转折和夸张比喻等通用表达节奏；不复制原文，不保留姓名、账号、地点、健康状况或具体关系事件。

## 编辑位置

在剧情工作台选择“编辑内容包与变量” → “普通 NPC 与热点闲聊”。

- 复用同一 `contactId`：形成同一 NPC 的多轮会话。
- 修改 `fanName`：可使用 `{{idolName}}` 或 `{{idolNickname}}` 制作名称联动。
- 热点闲聊统一选择“自动展示一问一答”：粉丝消息可以把几件事合并成一条长消息，成员回复一条；真人翻牌每条都会得到回复，不再使用无回复的连续气泡。
- “NPC 闲聊（玩家只读）”仍保留用于编辑器的连续气泡能力验证，不作为内容包写作方式。
